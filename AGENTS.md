## Architecture

```
Nginx (SSL termination)
  ├── / → Next.js frontend (:3000)
  ├── /api/* → Express backend (:4000)
  │               └── PostgreSQL (:5432)
  └── /projects → links to /api/projects
```

4 Docker services + 1 Nginx reverse proxy, orchestrated via `docker compose`.
